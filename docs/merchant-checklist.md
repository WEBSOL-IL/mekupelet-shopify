# Merchant admin checklist (Hebrew instructions, English handles)

Everything here is admin-side setup that the theme code expects. Handles and file names must match
exactly. Updated 2026-10-08 for the Home page (approximate build).

קיים הוא יופיע אוטומטית. חשובים לעמוד הבית:

## 2. קולקציות (Products → Collections)
קיימות כבר (handles בעברית, מחוברות לעיגולי הקטגוריות): `בגדי-ילדים`, `כלי-אוכל`, `ספרים`,
`צעצועים-ובובות`, `אביזרים`, `כלי-בית`. כולן ריקות (0 מוצרים) – צריך לשייך מוצרים (ידנית או בתנאי
אוטומטי). חסרה קולקציית **תחפושות** (העיגול קיים בלי קישור).

בינתיים כל סקשני המוצרים בעמוד הבית מושכים מ-`all` (כל המוצרים). כשתיצרו את הקולקציות הבאות,
אחליף אותן בסקשנים (או שתחליפו בעורך):

| handle | כותרת | הצעה לתנאי אוטומטי |
|---|---|---|
| `best-sellers` | מובילים | תגית `רב מכר` |
| `new` | חדש באתר | תגית `חדש` (או תאריך יצירה) |
| `sale` | במבצע | מחיר השוואה > מחיר |
| `age-0-6`, `age-6-12`, `age-1-1-5`, `age-1-5-2`, `age-2-3`, `age-3-plus` | רכישה לפי גיל | תגיות `גיל-0-6`, `גיל-6-12`, `גיל-12-18`, `גיל-18-24`, `גיל-24-36`, `גיל-3-plus` |

לקולקציה בלי סינון. אם תעדיפו מטא-שדה לגיל במקום תגיות, ספרו לי ואעדכן את הפרמטר בסקשן.

## 7. הגדרות חנות וערכה
- **פורמט מטבע**: Settings → Store details → Currency formatting: `{{amount_no_decimals}} ₪` (היום מוצג "69.00 NIS").
- **רשתות חברתיות**: Theme settings → Social media: קישורי אינסטגרם, פייסבוק, טיקטוק, וואטסאפ, יוטיוב (האייקונים בפוטר מופיעים רק כשיש קישור).
- **Hero**: ייצוא האיור של ה-hero מהרוויזיה כתמונה אחת (דסקטופ 2880×~1100, מובייל 780×~900) **בלי הטקסט**; הטקסט והכפתור יוגדרו בסקשן. עד אז נשאר הבאנר הישן.
- **קופסת ההפתעה**: תמונת הבאנר (עוגה + קופסה) מהרוויזיה.
- **ניוזלטר**: דפוסי הצד (ברווז, דג, פסים) כתמונה/ות או כרקע מלא.
- **אייקוני היתרונות** (6): SVG צבעוניים מהרוויזיה (סירה, מגן, תו 20, קוביות, וואטסאפ, משאית). בינתיים אייקוני Hyper בצבעי המותג.

## 9a. מפתח מיומנויות כרשימת בחירה (נוסף 2026-10-12)
ההגדרה הקיימת `custom.skills` היא טקסט עשיר (rich text) וריקה (0 מוצרים). אי אפשר לשנות סוג של הגדרה, לכן מוחקים ויוצרים מחדש באותו מפתח (התבנית של עמוד המוצר ממשיכה לעבוד).
**בוצע 2026-10-12 באישור המרצ'נט** (`scripts/create-choice-definition.py docs/import/skills-choices.json --execute`): ההגדרה החדשה היא רשימת טקסט מוגבלת ל-39 הערכים מ-`docs/import/skills-choices.json`, מוצמדת (pinned), נגישה ל-Storefront. לעדכון הרשימה בעתיד: לערוך את ה-JSON ולהריץ שוב (מעדכן את הבחירות בלבד).
הצעדים הידניים, לתיעוד בלבד:
| צעד | איפה |
|---|---|
| מחיקת ההגדרה הישנה | Settings → Custom data → Products → "מפתח מיומנויות" → Delete |
| הגדרה חדשה | Add definition: Name `מפתח מיומנויות`, Namespace and key `custom.skills`, Type: Single line text → **List of values**, Validation: "Limit to preset choices" ולהזין את 39 הערכים מהקובץ, אחד בכל שורה; Storefront access: on |

## 9b. מתאים לגיל כרשימת בחירה (בוצע 2026-10-12)
`custom.age_range` ("מתאים לגיל") הוחלף מטקסט חופשי לרשימת בחירה מ-12 ערכים (`docs/import/age-choices.json`): גיל לידה, 0-3 / 3-6 / 6-9 / 9-12 / 12-18 / 18-24 חודשים, שנתיים, 3 שנים, 4-5 שנים, 6-7 שנים, 8 ומעלה. אפשר לסמן כמה טווחים למוצר. הטאב בעמוד המוצר מציג אותם מופרדים בפסיק. לעדכון: לערוך את ה-JSON ולהריץ `python3 -I scripts/create-choice-definition.py docs/import/age-choices.json --execute`.

## 9c. מוצרים קשורים כווריאציות (בוצע 2026-10-14)
בעמוד המוצר, מתחת למחיר, מוצג בורר "דגמים נוספים" מתוך המטא-שדה **מוצרים קשורים** (`custom.linked_products`, רשימת מוצרים). למילוי: בכל מוצר בקבוצה (למשל כל צבעי המטבח של JABADABADO) לבחור את כל המוצרים של הקבוצה, כולל המוצר עצמו או בלעדיו (שניהם עובדים), ולמלא **תווית וריאציה** (`custom.variant_label`) בשם הקצר שיופיע מתחת לתמונה: שחור / ורוד / גדול. בלי תווית מוצג שם המוצר. דוגמה חיה: שלושת ספרי הסיר (טוסיקים / דובי / גילי); אפשר למחוק את הערכים שם.
